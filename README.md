\# SOC Security Monitoring and Vulnerability Assessment Lab



\## Project Objective

Build a hands-on Security Operations Center (SOC) lab

to monitor security events, detect suspicious activities,

investigate incidents, and assess network vulnerabilities.



\## Tools

\- Windows

\- Kali Linux

\- VMware

\- Git and GitHub

\- Python

\- Nmap

\- Wireshark

\- Splunk (planned)



\## Project Activities

1\. Network reconnaissance

2\. Network traffic analysis

3\. Security log monitoring

4\. Failed login detection

5\. Vulnerability assessment

6\. Python security log analysis
